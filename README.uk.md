## ⚡ Основні можливості

- **📦 Інсталятор в один клік (.exe):** Більше не потрібно розпаковувати архіви вручну.
- **🚀 Повністю автономний:** Включає .NET 8, бібліотеки C++ та кодеки GStreamer.
- **⚡ Апаратне прискорення Direct3D 11/12:** Плавні 60 FPS та висока чіткість тексту для онлайн-уроків та презентацій.
- **🖼️ Режим вікна без рамок:** Чітке відображення без рамок для презентацій та демонстрацій.
- **🛡️ Автоматичне налаштування Bonjour та Брандмауера:** Виправляє службу виявлення та відкриває порти.

---

## 📖 Швидкий старт

1. **Встановлення:** Завантажте та запустіть **[`UxPlayDesktop-Setup.exe`](https://github.com/jorjanion/uxplay-desktop/releases/latest)**.
2. **Запуск:** Відкрийте UxPlay Desktop і натисніть **«Запустити Сервер AirPlay»**.
3. **Підключення:** На iPad/iPhone відкрийте **Центр керування** > **Дублювання екрана** > виберіть **«UxPlay Windows»**.
