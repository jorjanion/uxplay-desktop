## ⚡ Hauptmerkmale

- **📦 1-Klick Nativer Installer (.exe):** Keine mühsamen ZIP-Archive mehr. Der Installer richtet alles automatisch ein.
- **🚀 100% Autark (Self-Contained):** Keine externen Downloads nötig (.NET 8 Desktop Runtime und C++ DLLs sind integriert).
- **⚡ Direct3D 11/12 Hardwarebeschleunigung:** Kristallklarer Text und flüssige 60 FPS für Präsentationen und Unterricht.
- **🖼️ Rahmenloser Fenstermodus:** Saubere, ablenkungsfreie Anzeige für Präsentationen und Bildschirmübertragungen.
- **🛡️ Automatische Reparatur von Bonjour & Firewall:** Konfiguriert den mDNS-Dienst und öffnet die erforderlichen Ports automatisch.
- **🌍 Mehrsprachig:** Unterstützt über 15 Sprachen mit sofortiger Umschaltung im Betrieb.

## 📖 Schnellanleitung

1. **Installieren:** Laden Sie **[`UxPlayDesktop-Setup.exe`](https://github.com/jorjanion/uxplay-desktop/releases/latest)** herunter und führen Sie den Installer aus.
2. **Server starten:** Öffnen Sie UxPlay Desktop und klicken Sie auf **„AirPlay Server Starten“**.
3. **Verbinden:** Öffnen Sie auf dem iPad/iPhone das **Kontrollzentrum** > **Bildschirmsynchronisierung** > wählen Sie **„UxPlay Windows“**.
