## ⚡ Основные преимущества

- **📦 Установщик .exe в один клик:** Никаких мучений с ZIP-архивами и ручной распаковкой.
- **🚀 Полностью автономный (Self-Contained):** Включает среду выполнения .NET 8, библиотеки C++ и плагины GStreamer.
- **⚡ Аппаратное ускорение Direct3D 11/12:** Плавные 60 кадров/с, идеальная четкость текста для онлайн-уроков и презентаций.
- **🖼️ Режим окна без рамок:** Чистый экран без отвлекающих рамок для презентаций и совместной работы.
- **🛡️ Автоматическая настройка Bonjour и Брандмауэра:** Автоматически устраняет ошибки службы mDNS и открывает нужные порты.
- **🌍 Более 15 языков интерфейса:** Мгновенное переключение без перезапуска программы.

## 📖 Быстрый старт

1. **Установка:** Скачайте и запустите **[`UxPlayDesktop-Setup.exe`](https://github.com/jorjanion/uxplay-desktop/releases/latest)**.
2. **Запуск:** Откройте UxPlay Desktop и нажмите **«Запустить Сервер AirPlay»**.
3. **Подключение:** На iPad/iPhone откройте **Пункт управления** > **Повтор экрана** > выберите **«UxPlay Windows»**.
