## ⚡ Caratteristiche Principali

- **📦 Programma di Installazione Nativo (.exe) in 1 Clic:** Nessuna gestione manuale di archivi ZIP. Configura tutto automaticamente.
- **🚀 100% Autonomo:** Include runtime .NET 8, librerie C++ e plugin GStreamer.
- **⚡ Accelerazione Hardware Direct3D 11/12:** Testo ultranitido per lavagne virtuali e 60 FPS fluidi.
- **🖼️ Modalità Finestra senza Bordi:** Visualizzazione pulita e senza distrazioni per presentazioni e condivisione dello schermo.
- **🛡️ Configurazione Automatica Bonjour e Firewall:** Ripara automaticamente servizi orfani e apre le porte di rete necessarie.
- **🌍 Supporto Multilingue:** Oltre 15 lingue integrate.

## 📖 Guida Rapida

1. **Installazione:** Scarica ed esegui **[`UxPlayDesktop-Setup.exe`](https://github.com/jorjanion/uxplay-desktop/releases/latest)**.
2. **Avvio:** Apri UxPlay Desktop e fai clic su **"Avvia Server AirPlay"**.
3. **Connessione:** Sul tuo iPad/iPhone, apri il **Centro di controllo** > tocca **Duplica schermo** > seleziona **"UxPlay Windows"**.
